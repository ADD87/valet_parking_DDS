## BATCH-049_052 收敛目标

本批次选择原始流程图里的“Stage 对外状态翻译与覆写链”作为收敛切口。

原始流程重点：

```text
Stage::ExecuteTaskOnOpenSpace()
  -> publishable_trajectory_data = speed_optimizer_trajectory
  -> frame.target_gear = speed_optimizer_trajectory.second

ValetParkingStageParking::Process()
  -> speed_task_interactive_stage 翻译为 WAITOBSTACLE / RUNNING
  -> IsReadyToFinishStage() 成立时覆写为 MISSIONFINISHED / PARKINGFINISHED
```

本批次当前实现：

```text
PATH_PARTITION ok
  -> decision_name
  -> finish_name
  -> destination_reached

SPEED_OPTIMIZER ok
  -> stage_name

STAGE_OUTPUT open_space
  -> stage_status
  -> task_chain
  -> path_decision
  -> finish_status
  -> destination_reached
  -> target_gear
  -> trajectory_type
  -> parking_status
  -> speed_interactive_stage
  -> finish_priority=finish_over_interactive
```

这不是把原始 `Frame/FunctionManager/HMI` 全部搬过来，而是在当前 DDS MVP 内先建立行为等价的输出收口契约。这样可以继续复用当前已经跑通的主链：

```text
SelectedSlot -> ROI_DECIDER -> PATH_PROVIDER -> PATH_PARTITION -> SPEED_OPTIMIZER -> PlanningTrajectory
```

## 已减少的差异

| 原始流程节点 | 之前差异 | 本批次收敛 |
|---|---|---|
| `OpenSpacePathPartition::Process` | 只看数字 decision/finish，不利于对照流程图 | 增加 `decision_name/finish_name/destination_reached` |
