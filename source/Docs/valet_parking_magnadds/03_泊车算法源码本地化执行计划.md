# 泊车算法源码本地化执行计划

- 计划编号：NEXT-032
- 日期：2026-07-27
- 目标：让 `applications` Git 仓库包含当前 MagnaDDS 泊车 MVP 构建所需的泊车算法源码，解除对外部 `E:\APA\DDS\parking_algorithm_standalone` 绝对路径的构建依赖。
- 决策记录：`decision_records/DR-004_泊车算法源码本地化策略.md`

---

## 1. 当前问题

当前 `applications/source/valet_parking/CMakeLists.txt` 仍通过：

```cmake
${APP_SOURCE_ROOT}/../../../../parking_algorithm_standalone
```

引用外部 standalone 算法源码。

这对当前机器能工作，但对交接、换机和后续 CI 不够稳。只拿到 `applications` 仓库时，无法独立构建当前 DDS 泊车 MVP。

---

## 2. 本地化目标路径

建议目标路径：

```text
applications/source/valet_parking/algorithm/parking_algorithm_standalone
```

该目录只保存当前 MVP 已实际编译并验证过的算法源码和头文件依赖，不作为完整 standalone 镜像。

---

## 3. 迁移范围

以当前 `valet_parking/CMakeLists.txt` 实际编译源文件为准，当前最小集合包括：

| 分组 | 内容 |
|---|---|
| ROI/math | `common/math/*.cc` 中几何、角度、搜索、插值、坐标转换相关文件 |
| vehicle config | `common/configs/vehicle_config_helper_simple.cc` |
| ROI decider | `planning/tasks/deciders/open_space_decider/open_space_roi_decider.cc`、`open_space_obstacle.cc`、`open_space_fine_tuning.cc` |
| PATH_PROVIDER | `planning/open_space/coarse_path_generator/**`、`open_space_path_generation/open_space_path_generator.cc` |
| PATH_PARTITION | `open_space_path_partition/open_space_path_partition.cc` |
| SPEED_OPTIMIZER | `planning/common/speed/**`、`planning/common/trajectory/**`、`planning/common/trajectory1d/**`、`open_space_speed_optimizer/**` |

实施时必须同时复制这些 `.cc` 对应的 `.h`、`.hpp` 和被 include 的最小头文件依赖。

---

## 4. 禁止迁移内容

不得迁入：

- 整个 `parking_algorithm_standalone` 目录。
- `proto/**/*.pb.*`。
- ROS2 节点、launch、demo、测试 out、历史构建产物。
- 未确认进入当前 workspace Thirdparty 的 IPOPT/glog/gflags/Abseil 依赖。
- 完整 `OpenSpacePathProvider` 大类线程管理、完整 `Frame/DependencyInjector`、NLP smoother 或完整 Stage 状态机。

---

## 5. 执行步骤

1. 生成当前 CMake 实际源文件清单。
2. 从 `E:\APA\DDS\parking_algorithm_standalone` 复制清单内 `.cc` 文件到目标目录，保留相对目录结构。
3. 用编译错误和 include 追踪补齐最小头文件依赖。
4. 修改 `applications/source/valet_parking/CMakeLists.txt`：
   - `STANDALONE_PARKING_ROOT` 改成本地相对路径。
   - fatal error 文案改成本地算法目录缺失。
   - 不再引用外部绝对路径。
5. x86 构建并运行 smoke：
   - 默认 valid。
   - `parking-seq-changes` 或 `target-moves`。
   - all-valid 辅助输入。
6. m57 交叉编译并检查 ELF 与 MagnaDDS 依赖。
7. 更新 `README.md`、`STATUS.yaml` 和新状态快照。
8. Git 提交并推送。

---

## 6. 验收标准

NEXT-032 完成时必须满足：

- `applications/source/valet_parking/CMakeLists.txt` 不再依赖 `E:\APA\DDS\parking_algorithm_standalone`。

- x86 构建通过。
- x86 核心 smoke 回归通过。
