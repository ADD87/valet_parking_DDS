## 2. 用户疑问结论

Adapter 长期不应该有几千行。

当前 `valet_parking_stage_parking_adapter.cpp` 超过 5000 行，是过渡阶段的技术债：DDS 输入输出、业务流程编排、轻量 Stage 投影、task fallback 和 smoke 诊断都混在一起。正确目标是：

```text
ValetParkingComponent
  -> 只负责 DDS reader/writer 和 worker loop

ValetParkingStageParkingAdapter
  -> 只做 DDS 类型翻译、少量输入校验、调用 Stage facade

ValetParkingStageParkingStageLite / 后续 StageFacade
  -> 承接 Process、task chain、Frame/OpenSpaceInfo/PlanningContext 更新和 Stage 输出契约
```

本批先把 Stage 骨架接上；下一批开始物理瘦身 Adapter。
