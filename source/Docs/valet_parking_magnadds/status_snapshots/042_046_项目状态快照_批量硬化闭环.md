# 项目状态快照 042_046：批量硬化闭环

日期：2026-07-29

## 本批次结论

`BATCH-042_046` 已完成。

这批不是继续扩大算法范围，而是把已经接通的两条主链路做硬：

```text
SelectedSlot -> ROI_DECIDER -> PATH_PROVIDER -> PATH_PARTITION -> SPEED_OPTIMIZER -> PlanningTrajectory
ParkingCommand DIRECT_* -> OPEN_SPACE_STRAIGHT_PATH -> SPEED_OPTIMIZER -> PlanningTrajectory
```

批量修订后，direct、command、stage-control、parking-out unsupported 和主链路诊断有了统一的可检索契约，x86 批量 smoke 可一次性覆盖关键回归。

## 代码变更

- `applications/source/valet_parking/src/valet_parking_stage_parking_adapter.cpp`
  - 新增统一的 stage-control 诊断拼接入口。
  - direct 分支输出 `command_action`、`stage_status=direct_control`、`task=OPEN_SPACE_STRAIGHT_PATH`、`trajectory_type=NORMAL`、`parking_status=direct_stop_path/direct_moving`。
  - `PAUSE/BRAKE/FINISH` 输出 `stage_status`、`task=STAGE_CONTROL_STOP`、`trajectory_type=SHORT_PATH`、`parking_status`；`FINISH` 明确输出 `finish_status=MISSIONFINISHED`。
  - `PARKING_OUT_*` 明确输出 `stage_status=unsupported`、`task=UNSUPPORTED_PARKING_OUT`、`parking_status=parking_out_unsupported`、`unsupported_in_mvp`。

- `applications/source/valet_parking/src/valet_parking_component.cpp`
  - `ParkingCommand.reset_history` 被消费后打印一次性日志，随后清回 false，避免同一条命令无限重复重置历史。

- `applications/source/valet_parking_tools/smoke_valet_parking_x86.sh`
  - 支持 `--command-reset-history`。
  - 增加 `parking-out-left/right/front/back` smoke 契约检查。
  - 增加 direct、pause、brake、finish 的标准化状态字段检查。
  - 将 `far-localization/far-obstacles/many-obstacles` 这类辅助输入负向场景从普通 valid threaded provider 成功断言中拆出，避免测试预期互相冲突。
  - WSL 读取 Windows 盘日志时偶发 `grep: No data available`，脚本已把底层 grep stderr 静默化；真正失败仍由脚本自己的 missing 消息和退出码表达。

- `applications/source/valet_parking_tools/smoke_valet_parking_batch_042_046.sh`
  - 新增批量 smoke 入口，串行覆盖 valid、timeout、multi-lot、direct、reset_history、pause/brake/finish、invalid、parking-out unsupported、target/path_id/far-obstacles 回归。
