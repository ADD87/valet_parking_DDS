## 3. 与原始 TempAPA_Code 的差异总结

| 维度 | 原始 TempAPA_Code | 当前 libvalet_parking.so |
|---|---|---|
| Stage 入口状态机 | `SetParkingType` / `IsBrakeCondition` / `IsReadyToFinishStage` | lite 投影实现，核心逻辑一致 |
| Task 调度 | `Stage::ExecuteTaskOnOpenSpace` 多态 task_list_ | adapter 直接顺序调用 standalone 对象 |
| ROI Decider | 5,642 lines (完整版，含泊出/NNS) | 4,268 lines (standalone 精简版，仅泊入) |
| PathProvider | ThreadManager + HybridAStar + NLP Smoother | 同，通过 standalone 本地副本接入 |
| PathPartition | 路径仲裁 + HMI 收口 | 同，通过 standalone 接入 |
| SpeedOptimizer | PathHandle + ST 采样 + 碰撞状态机 | 同，FreeSpace/wheel_mask 等感知依赖用默认值安全跳过 |
| 通信层 | ROS2/SOA-DDS | MagnaDDS（完全重写） |
| 中间件适配 | 0 | 1,349 lines DDS 生命周期 |
