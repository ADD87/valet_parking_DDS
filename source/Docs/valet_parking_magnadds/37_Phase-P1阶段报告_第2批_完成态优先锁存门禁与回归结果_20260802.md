## 一、本批目标

在第1批“direct release 锁存”基础上，补齐一个关键一致性边界：

- `stage_exit_requested=true` 后应**优先进入 FINISH_HOLD**，避免被新输入重入普通链；
- 同时做第2批回归：`direct-backward-release` + `near-destination` 交叉验证。

## 二、代码改动

1. 文件：`source/valet_parking/src/valet_parking_stage_parking_adapter.cpp`
   - 新增 `publish_finish_hold` 统一发布分支，避免重复拼接和分支偏差；
   - 在 command 分支内增加优先门禁：
     - 当 `runtime_->stage_exit_requested` 已锁存时，直接 `return publish_finish_hold();`
   - 保留并复用原有非 command 路径的 `stage_exit_requested` 收口。

> 结果：`stage_exit_requested` 从“后置收口”提升为“command + normal 的一致性优先门禁”。
